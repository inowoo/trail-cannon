# Trail Cannon

高速移動しながら肩キャノンを無制限に連射し、画面に点線状の軌跡を描く気持ちよさを主役にした、Webブラウザ向け横スクロール・アクションシューティングの試作です。

このREADMEを仕様書の正本として、実装変更のたびに更新します。

## 現在のバージョン

**Prototype v0.1.0**

まず次の一点を検証します。

> 高速で移動しながら肩キャノンを大量に撃ち、点線の軌跡が画面を流れていく感触そのものが気持ちいいか。

## コンセプト

- 横スクロールのロボットアクション
- 肩キャノンは弾数無制限
- リロードなし
- 連射可能
- 弾そのものより「飛翔軌跡」が画面を作る
- 軌跡は点線状で、短時間だけ残ってフェードアウトする
- 軌跡自体には当たり判定を持たせない
- 高速移動＋高速連射で画面に大量の軌跡が走ることを重視
- 敵は大量に埋め尽くすより、軌跡が見える程度の密度にする

## 操作

### スマートフォン / タブレット

横向きで遊ぶ想定です。

- **画面左側をドラッグ**：移動
- **画面右側をタッチ / ドラッグ**：その方向へ照準
- **右側を押している間**：肩キャノンを自動連射
- **8MHz / NORMAL ボタン**：高速モード切り替え

左右を同時に触ることで、移動しながら射撃できます。

### PC

- **WASD / カーソルキー**：移動
- **マウスカーソル**：照準
- **マウス左ボタン長押し**：連射
- **Space / O**：8MHzモード切り替え

## 8MHzモード

昔のPCでクロック切り替えによってゲーム全体が高速化した感触をモチーフにした試験機能です。

8MHzモードでは、

- 自機の移動速度アップ
- 発射間隔短縮
- 弾速アップ
- 敵の移動も少し高速化
- 軌跡が大量に流れやすくなる

ゲームバランス用の必殺技ではなく、現段階では「高速化したときの気持ちよさ」を比較するためのモードです。

## 画面設計

内部描画解像度は 960 x 540 を基準にし、実際のブラウザサイズに合わせて拡大縮小します。

スマートフォンではブラウザの1画面に収まるようにし、スクロールやピンチズームなどゲーム操作を邪魔する標準ジェスチャーは抑制します。

## 軌跡表現

各弾は一定間隔で過去位置を記録します。

記録位置は、

- 小さな点
- 古い点ほど薄く
- 一定時間で消滅

として描画します。

弾が高速で飛んだときも一本の実線にはせず、点線が「ダーッ」と流れる見た目を優先します。

## 開発方針

1. まず触って気持ちいいかを確認する
2. 面白さに直接関係しない機能は後回し
3. 変更した仕様はREADMEへ随時反映する
4. スマホ / タブレットでのタッチ操作を優先する
5. PCブラウザでも確認できるようにする
6. 外部ライブラリを極力使わず、HTML / CSS / JavaScriptだけで軽く作る
