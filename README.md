# Trail Cannon

高速移動しながら肩キャノンを無制限に連射し、点線状の飛翔軌跡を画面に描く気持ちよさを主役にした、Webブラウザ向け横スクロール・アクションシューティングです。

このREADMEを仕様書の正本として、実装変更のたびに更新します。

## 現在のバージョン

**Prototype v0.2.1**

## ゲームの流れ

1. タイトル画面で **START**
2. 通常敵を倒しながら進む
3. 通常敵を20体倒すとボス出現
4. ボスを倒すと **STAGE CLEAR**
5. HPが0になると **GAME OVER**

現段階では1ステージ構成です。

## プレイヤー

- HP最大値：100
- 敵弾を受ける：10ダメージ
- 敵に体当たりする：18ダメージ
- ダメージ後は短時間無敵
- HPが0になるとゲームオーバー

## 回復アイテム

通常敵を**6体倒すごと**にリペアアイテムが出現します。

取得するとHPを**30回復**します。最大HPを超えては回復しません。

## 通常敵

- 右側から出現
- 左へ移動しながら上下に揺れる
- 一定間隔でプレイヤーを狙って弾を撃つ
- プレイヤー弾1発で撃破
- 撃破数がステージ進行条件になる

## ボス

通常敵を20体倒すと、プレイヤーと似た肩キャノン型の敵が出現します。

- HP：80
- 画面右側を上下移動
- プレイヤーを狙って連射
- 赤い点線軌跡を持つ弾を撃つ
- 撃破するとステージクリア

現在は最初の試作ボスで、今後攻撃パターンを追加予定です。

## CLOCK UP

以前の「8MHz」表記は廃止し、**CLOCK UP** に変更しました。

CLOCK UP中は、

- 自機移動速度アップ
- 発射間隔短縮
- 弾速アップ
- 敵や背景スクロールも少し高速化
- 点線軌跡が大量に流れやすくなる

ゲーム中の右上ボタン、またはPCの **Space / O** で切り替えます。

## 操作

### スマートフォン / タブレット

横向き推奨です。

- **画面左側をドラッグ**：移動
- **画面右側をタッチ / ドラッグ**：照準
- **右側を押している間**：肩キャノンを自動連射
- **CLOCK UPボタン**：高速モード切り替え

### PC

- **WASD / カーソルキー**：移動
- **マウスカーソル**：照準
- **マウス左ボタン長押し**：連射
- **Space / O**：CLOCK UP切り替え
- **Enter**：タイトルからスタート

## 月面風地形

画面下部には月面や小惑星表面をイメージした凹凸地形があります。

- 地形はゲーム進行に合わせて左へ流れる
- 複数のsin波を合成して凹凸を作る
- プレイヤーは地面より下には移動できない
- クレーター風の円弧や岩を描画する

現在は地形との接触でダメージは受けません。

## 軌跡表現

プレイヤー弾は黄色系、敵弾は赤系の点線軌跡を残します。

軌跡そのものに当たり判定はありません。
