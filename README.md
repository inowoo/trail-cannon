# Trail Cannon

高速移動しながら肩キャノンを無制限に連射し、点線状の飛翔軌跡を画面に描く気持ちよさを主役にした、Webブラウザ向け横スクロール・アクションシューティングです。

このREADMEを仕様書の正本として、実装変更のたびに更新します。

## 現在のバージョン

**Prototype v0.3.0**

## ゲームの流れ

1. タイトル画面で **START**
2. 雑魚敵を撃破しながら進む
3. 規定数を倒すとボス出現
4. Stage 1のボスを倒すとStage 2へ進む
5. Stage 2では敵構成・出現頻度・敵弾・ボスが強化される
6. Stage 2ボス撃破で **ALL STAGES CLEAR**
7. HPが0になると **GAME OVER**

## プレイヤー

プレイヤー機は、頭・胴体・腕・脚が見える人型重装ロボットです。

- 赤系の装甲
- 頭部センサー
- 太めの胴体と脚
- 肩キャノン
- 肩キャノンだけが照準方向へ向く
- HP最大値：100
- ダメージ後は短時間無敵

ゲーム開始時・各ステージ開始時のボム所持数は2です。

## 雑魚敵

### UFO型

- ゆらゆら上下移動
- プレイヤー狙い弾
- 耐久力は低い
- Stage 1で多めに登場

### ジェット型

- 高速で画面を横切る
- 耐久力は低い
- Stage 2では射撃頻度が上がる
- スピードで圧力をかける敵

### 人型ロボ型

- プレイヤーに近い人型シルエット
- 他の雑魚より高耐久
- 肩付近から2連射
- Stage 2で出現率が上がる

## ステージ

### Stage 1

- 撃破目標：20体
- UFO中心
- ジェット・ロボも出現
- 最後に人型ロボボス

### Stage 2

- 撃破目標：28体
- 敵の最大同時出現数アップ
- ジェット・ロボの比率アップ
- 敵弾速度アップ
- スクロール速度アップ
- ボスHP・連射数・弾速アップ
- 背景と地表色も変化

Stage 1クリア後は自動的にStage 2へ進みます。

ステージ移行時はHPを25回復し、ボムを2個へ補充します。

## ボス

各ステージ最後に大型の人型ロボが出現します。

- 肩キャノンから赤い軌跡の弾を連射
- 画面右側を上下移動
- Stage 2ではHPと攻撃密度が上昇
- Stage 2では追加の扇状射撃も使用

ボス出現時にボムを1個補充します。最大所持数は3です。

## BOMB

緊急回避用の近距離攻撃です。

- 自機を中心に半径約230の衝撃波
- 範囲内の敵弾を消去
- UFO・ジェットはほぼ一掃
- 人型雑魚には大ダメージ
- ボスには小ダメージ
- 発動直後は短時間無敵
- 画面全体ではなく、自機周辺だけを安全にする

### 操作

- スマホ / タブレット：右上の **BOMB** ボタン
- PC：**B / X**

## CLOCK UP

現段階では実験機能として残しています。

- 自機移動速度アップ
- 発射間隔短縮
- 弾速アップ
- 敵や背景スクロールも少し高速化
- 点線軌跡が大量に流れやすくなる

将来的にはゲージ制などへの再設計候補です。

## 操作

### スマートフォン / タブレット

横向き推奨です。

- **画面左側をドラッグ**：移動
- **画面右側をタッチ / ドラッグ**：照準
- **右側を押している間**：肩キャノンを自動連射
- **CLOCK UPボタン**：高速モード切り替え
- **BOMBボタン**：近距離ボム

### PC

- **WASD / カーソルキー**：移動
- **マウスカーソル**：照準
- **マウス左ボタン長押し**：連射
- **Space / O**：CLOCK UP
- **B / X**：BOMB
- **Enter**：タイトルからスタート / リトライ

## 回復アイテム

雑魚敵を6体倒すごとにリペアアイテムが出現します。

取得するとHPを30回復します。

## 地形

月面や小惑星表面をイメージした凹凸地形です。

- 地形は左へスクロール
- クレーター風の模様
- ステージごとに色調を変更
- プレイヤーは地面より下には移動できない

## 軌跡表現

- プレイヤー弾：黄色系の点線軌跡
- 敵弾：赤系の点線軌跡
- 軌跡自体には当たり判定なし

大量の弾を撃ったときに点線が画面へ残る視覚的な気持ちよさをゲームの中心にします。

## 開発方針

1. 触ったときの気持ちよさを最優先する
2. 点線軌跡をゲームの視覚的な主役にする
3. 変更した仕様はREADMEへ随時反映する
4. スマホ / タブレットのタッチ操作を優先する
5. PCブラウザでも遊べるようにする
6. HTML / CSS / JavaScriptだけで軽く作る
7. GitHub Pages更新時はアセットURLのバージョンも更新し、古いキャッシュとの混在を避ける
